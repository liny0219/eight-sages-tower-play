# 歧路 · 八贤之塔

**0.2.3 · Web 试玩版**  ·  [在线游玩](https://liny0219.github.io/eight-sages-tower-play/)

以欧休提为首位旅人的非官方同人卡牌爬塔游戏。横屏画面始终沿可用窗口长边显示；手机请按画面方向横放游玩。无需浏览器方向锁，保持同一横向游戏布局；全屏为可选显示方式。

- 单个存活敌人时，点单体卡直接使用；多个敌人时，选牌后沿导线点目标。自身／全体卡立即执行，也可拖放出牌。
- 悬停查看说明，长按手牌打开详情。`1–9`、`0` 选牌，`Enter` 出牌，`Tab` 换目标，`B` 增幅，`E` 结束回合。
- 右键或 `Esc` 取消选牌；`Esc` 关闭弹窗／暂停，设置内切换全屏、声音和动态效果。

进度保存在当前浏览器的网站数据中。清理网站数据会删除进度；不会自动同步到其他设备。首次加载需要下载游戏资源，需支持 WebAssembly 和 WebGL 2 的浏览器。

这里仅分发预先构建的 Web 运行文件，不提供开发工程。下载完整目录后，可在该目录运行 `python3 -m http.server 8000`，再打开 `http://localhost:8000/`；无需重新构建游戏。不能通过直接双击 HTML 文件运行，也未启用 Service Worker 离线缓存。
