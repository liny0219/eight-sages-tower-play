# 歧路 · 八贤之塔

**0.4.3 · Web 试玩版**  ·  [在线游玩](https://liny0219.github.io/eight-sages-tower-play/)

以欧休提为首位旅人的非官方同人卡牌爬塔游戏。横屏画面默认沿可用窗口长边显示；手机请按画面方向横放游玩。无需浏览器方向锁，保持同一横向游戏布局；全屏为可选显示方式。资源加载页点击「旋转画面」可在长边横屏和短边横屏之间切换，重新加载后保持所选适配；版本号与「更新日志」可在游戏标题页查看。

- 点击怪物锁定目标，名字前的金色准星表示当前目标；点击卡牌直接使用。破防以独立紫色标记提示。点击手牌左侧 BP 切换增幅，牌面直接显示最终数值。
- 长按怪物或卡牌查看场景内半透明浮窗，点击短语继续阅读特殊规则、升级与 BP 效果；点空白收起。顶部「行动」可查看牌堆、捕获与持续能力；仅查看不会消耗资源。
- 顶部「行囊」查看遗物与药剂；`1–9`、`0` 使用对应卡牌，`Tab` 换目标，`B` 增幅，`E` 结束回合。
- 右键或 `Esc` 取消选牌；`Esc` 关闭弹窗／暂停，设置内切换全屏、声音和动态效果。

进度保存在当前浏览器的网站数据中。清理网站数据会删除进度；不会自动同步到其他设备。首次加载需要下载游戏资源，需支持 WebAssembly 和 WebGL 2 的浏览器。

这里仅分发预先构建的 Web 运行文件，不提供开发工程。下载完整目录后，可在该目录运行 `python3 -m http.server 8000`，再打开 `http://localhost:8000/`；无需重新构建游戏。不能通过直接双击 HTML 文件运行，也未启用 Service Worker 离线缓存。
